# Каталог одежды

Адаптивный прототип на HTML, CSS и JavaScript. Без сборки и внешних runtime-зависимостей.

Локальный запуск: `python3 -m http.server 4173 --directory dist`.

Демонстрационные товары хранятся в `dist/app.js`. Набор содержит названия, цвета, описания и альтернативный текст; изображения находятся в `dist/assets`.

Сетка: 3 колонки от 1024 px, 2 от 600 px, 1 до 599 px. Товар открывается в нативном HTML dialog. Escape и кнопка закрытия возвращают фокус карточке. На мобильном просмотр занимает весь экран. Поддержаны safe-area, уменьшение движения и повышенный контраст.

Это демонстрация дизайна. Реальные товары, покупки, бот и сервер не подключены.
